# 五类策略在 Bi-GRACE 上的实验范式研判

更新日期：2026-06-17

## 共性

五类策略都沿用各自原始训练范式，在同一组 Bi-GRACE 四任务示范和闭环评估协议下比较；核心区别不在任务本身，而在它们如何表征观测、如何生成一段双臂动作，以及是否额外引入物体级几何或语言先验。

Bi-GRACE 的阶段、角色和功能关键点主要承担诊断评估作用；除个别方法需要语言提示或点流构造外，这些结构标签不应被表述为所有策略都显式使用的训练监督。

## 策略差异

- **ACT_BC_VISION**：直接从视觉观测和机器人状态回归一段末端执行器动作，是最接近纯视觉行为克隆的序列预测基线。
- **BIMANUAL_PERACT**：把多视角 RGB-D 场景转成三维体素表示，并通过离散 Q 值选择双臂动作，核心专长是显式三维空间动作搜索。
- **DIFFUSION_POLICY**：以视觉和低维状态为条件，对未来连续动作序列进行去噪生成，核心专长是建模多步动作分布而非单点回归。
- **PPI**：在动作学习之外构造并预测目标物体 point flow，用物体级运动先验约束 grasp-enabling transformation，是五者中结构化几何监督最强的一类。
- **OPENPI_POLICY**：在预训练视觉-语言-动作模型基础上适配 RLBench 双臂数据，用语言提示、三视角图像和机器人状态生成短时关节动作序列，核心特殊性是引入通用 VLA 先验。

## 可压缩写作口径

这组实验比较了五类代表性策略在同一 Bi-GRACE 任务协议下的表现：从直接视觉行为克隆、三维体素 Q 搜索、扩散式动作序列生成，到点流条件化策略和预训练 VLA 微调。它们主要差异在于动作生成机制与可用先验，而非是否共同使用 Bi-GRACE 的诊断标签；阶段、角色和关键点信息应主要作为评估解释工具来使用。
